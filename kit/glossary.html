Every term used in the first seven lectures, in plain words, with what it means for a robot and the lecture where it first appears. The wording is deliberately simple so you can quote or adapt it.

TermIn plain wordsFor a robotLecture
Augmented matrixA matrix with the right-hand side written next to it as an extra column, so both are processed togetherThe robot's geometry and its latest measurements carried through the solve side by side2
Back-substitutionSolving a triangular system from the last equation upward, feeding each answer into the equation aboveUsing the quantity that is known directly to unlock the next one2
Block multiplicationMultiplying matrices that have been cut into blocks, treating the blocks like numbersHow two poses multiply: rotation blocks compose, position blocks add3
CoefficientA fixed number that multiplies an unknownA geometric constant of the machine: a length, a lever arm, the sine of a mounting angle1
Column pictureReading A x = b as "which mix of the columns of A gives b?"Each actuator owns one column; solving means choosing how hard to drive each1
Column space C(A)The set of all combinations of the columns of A; everything A x can equalEverything the machine can produce: every hand velocity, every net force5, 6
Dependent columnsColumns where at least one is a combination of the othersAn actuator that adds no new direction6
Dot productMultiply two lists entry by entry and addOne output computed as a weighted sum of the inputs1
Echelon form UThe staircase-shaped matrix left by elimination: each pivot sits to the right of the one aboveThe task directions sorted out one by one7
EliminationSubtracting multiples of one equation from others to remove an unknown from themThe standard method inside every solver a robot runs2
Elimination matrix EThe identity matrix with one extra entry; multiplying by it performs one elimination stepOne step of the procedure, stored so it can be replayed or undone2
Forward kinematicsComputing where the hand is from the joint anglesA product of one transform per link3
Forward problemGiven the commands x, compute the result A xPredicting motion from motor commands1
Free column / free variableA column with no pivot; its unknown can be given any valueA spare actuator the designer or controller may use as they like7
Gauss-Jordan eliminationReducing [A I] until it reads [I A⁻¹]Solving for every unit command at the same time3
Homogeneous transformA matrix that holds a rotation and a position together, so poses can be multipliedThe standard way robot software stores "where this part is and which way it faces"3
Identity matrix IOnes on the diagonal, zeros elsewhere; multiplying by it changes nothing"Do nothing"2
Ill-conditionedNearly singular: a solution exists but changes a lot when the data changes a littleSmall sensor noise becomes large error; joint speeds spike1
Independent columnsColumns none of which is a combination of the othersActuators that each add a new direction6
Intersection of subspacesThe vectors that belong to both; always a subspaceThe motions two robots can both perform6
Inverse A⁻¹The matrix that undoes A: A⁻¹A = IUndoing a motion, or switching viewpoint between frames2, 3
Inverse problemGiven the wanted result b, find the commands x with A x = bWorking out motor commands for a wanted motion1
Invertible / non-singularHaving an inverse; A x = b has exactly one solution for every bA machine with full authority and no blind direction1, 3
Jacobian JThe matrix that turns joint speeds into hand velocity; column i is the hand velocity when only joint i turnsThe single most used matrix in arm control1
LDUA = L D U with ones on the diagonals of L and U and the pivots in DThe pivots, kept separately as the "scale" of each stage4
Linear combinationMultiply vectors by numbers and add the resultsThe combined effect of several actuators1
Linear equationAn equation in which unknowns are only scaled and addedA sensor reading or a balance of forces, written as a fact about unknowns1
Lower triangular LA matrix with zeros above the diagonalThe record of elimination's multipliers4
LU factorizationWriting A = L U: elimination saved for reusePrepare once, then solve each new right-hand side cheaply4
MatrixA rectangle of numbers; here, the coefficients of a systemThe machine's geometry in numerical form1
MultiplierThe number of times a pivot row is subtracted from a row below itOne entry of the stored recipe L2
Nullspace N(A)The set of all x with A x = 0Everything the actuators can do that has no effect on the task: self-motion, cancelling thrusts6
Nullspace matrix NA matrix whose columns are the special solutionsA ready basis of self-motions7
OdometryEstimating how far a robot has moved by adding up small measured motionsSolving the wheel equations every tick and summing the results2
Partial pivotingExchanging rows so that the largest available entry becomes the pivotProtecting the answer from rounding error by not dividing by small numbers5
Permutation matrix PThe identity matrix with its rows reorderedReordering equations or relabelling motors2, 4, 5
PivotThe entry elimination divides by at each stage; it must be non-zeroHow firmly an equation determines its unknown2
Pivot column / pivot variableA column that contains a pivot; its unknown is determined by the othersAn actuator whose command is forced once the free ones are chosen6, 7
Rank rThe number of pivotsThe number of independent directions a machine really commands7
Rank oneA matrix that is one column times one rowA one-trick machine: every output lies along one direction3
RedundancyHaving more actuators than the task needs: n − r > 0Spare freedom for avoiding obstacles, sharing load or surviving a failure6, 7
Reduced row echelon form REchelon form taken further: pivots equal to 1, zeros above and below themThe clearest statement of which unknowns depend on which7
Right-hand side bThe numbers on the other side of the equals signWhat was measured, or what is wanted1
Row exchangeSwapping two equations to bring a usable pivot into placeAsking a different sensor first2
Row pictureReading A x = b one equation at a time: lines or planes that must meetEach measurement narrows down where the robot can be1
Self-motionA joint motion that leaves the hand where it isA vector in the nullspace of the Jacobian6
SingularNot invertible: the columns do not fill the space, so A x = b has no solution or infinitely manyA missing direction of motion or sensing1
SingularityA pose at which a robot's matrix becomes singularThe straight arm; the robot in line with both beacons1
Special solutionA solution of A x = 0 with one free variable set to 1 and the rest to 0One basic self-motion: move one spare joint, let the others compensate7
SubspaceA set of vectors that contains zero and is closed under adding and scalingThe set of all motions a (linear, unconstrained-in-size) machine can make5
Symmetric matrixA matrix equal to its transposeInertia and covariance matrices; anything of the form JᵀJ5
Thrust allocationChoosing individual thruster forces that add up to a wanted net force and torqueSolving B f = b for the thrust vector1
Transpose AᵀThe matrix with rows and columns swappedThe route forces take: τ = Jᵀ F4, 5
TriangulationFinding a position from the directions to known pointsThe row picture: each bearing is one line1
Union of subspacesThe vectors that belong to either; usually not a subspace"What robot A or robot B can do" cannot be freely combined6
UnknownA number we are solving forA position to estimate, or a motor command to choose1
Upper triangular UA matrix with zeros below the diagonalA system ready for back-substitution2
VectorA list of numbers, pictured as an arrow from the originA velocity, a force, a set of joint speeds1
Vector spaceA set of vectors in which adding and scaling never leave the setThe space of all velocities, forces or joint speeds5
Zero vectorThe vector of all zeros; every subspace contains itStanding still is always an option5
