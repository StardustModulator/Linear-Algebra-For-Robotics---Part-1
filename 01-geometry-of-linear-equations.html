The Geometry of Linear Equations

One set of equations, seen three ways. As rows it is lines that cross. As columns it is arrows that add up. As a matrix it is one short sentence, Ax = b. A robot leans on all three: rows are what its sensors tell it, columns are what its motors can do.

1.0

Start here: what is a linear equation?

Nothing assumed. If you can add and multiply, you can follow this page.

An equation is a fact about numbers you do not know yet. The unknown numbers are called unknowns, and we name them x, y, z.

An equation is linear when each unknown is only multiplied by a plain number and the results are added. So 2x − y = 0 is linear. An equation with x², xy or sin x in it is not. Linear equations are the ones we can always solve, quickly and exactly, which is why engineers bend almost every problem into this shape.

The numbers that multiply the unknowns are the coefficients. The number on the other side of the equals sign is the right-hand side. The whole lecture uses one small example with two equations and two unknowns:

The lecture's example
2x − y = 0  and  −x + 2y = 3

Two facts, two unknowns. A solution is a pair (x, y) that makes both facts true at once. Here it is x = 1, y = 2. Check it: 2·1 − 2 = 0 and −1 + 2·2 = 3.

Professor Strang's point in this first lecture is that there is more than one way to see such a system, and the less obvious way turns out to be the important one.

Robotics linkwhy a robot cares

A robot is a machine that solves linear equations all day

Every sensor reading is a fact about where the robot is, so each reading is an equation. Every motor is a number the robot gets to choose, so each motor is an unknown. Finding a position from sensor readings, or motor commands from a desired motion, means solving a system like the one above. A typical arm controller does it a thousand times each second.

1.1

The row picture: every equation is a line

Look at one equation at a time.

Take the first equation alone, 2x − y = 0. Many pairs satisfy it: (0, 0), (1, 2), (2, 4). Plot them and they fall on a straight line. That is true of every linear equation in two unknowns: one equation, one line.

The second equation, −x + 2y = 3, draws a second line. A point that satisfies both equations must sit on both lines, so the solution is the point where the lines cross. This is the row picture, named because each row of the system gives one line.

Two lines can do three things, and each one tells you something about the equations:

  • Cross once. Exactly one solution. This is the normal, healthy case.
  • Run parallel. They never meet, so there is no solution. The two facts contradict each other.
  • Lie on top of each other. Every point of the line is a solution. The second fact repeats the first, so you really have only one equation.

The last two are the singular cases. Remember that word. It comes back in every lecture.

Robotics linklocalization

Each sensor reading is a line the robot must be standing on

A robot in a warehouse sees a beacon and measures the compass direction to it. That one number does not tell the robot where it is. It tells the robot it is somewhere on a line that passes through the beacon in that direction. A second beacon gives a second line. The robot is at the crossing. Sailors call this taking a fix. Robots call it triangulation, and it is the row picture and nothing more.

If the bearing to a beacon at (p, q) is the angle φ, the line is (sin φ) x − (cos φ) y = (sin φ) p − (cos φ) q. It looks busy, but φ, p and q are all known numbers, so this is a linear equation in x and y, just like 2x − y = 0.

Watch out

Nearly parallel lines still cross at one point, so on paper the system has a perfectly good solution. In a real robot it is a bad solution, because the crossing point moves a long way when a measurement changes a little. Engineers call such a system ill-conditioned. Singular is the limit of ill-conditioned.

1.2

The column picture: arrows that add up

Same equations, read downward instead of across. This is the view that matters most.

Write the same two equations again, but this time collect everything that multiplies x into one stack and everything that multiplies y into another:

The same system, by columns
x+y=

Read the top entries and you get 2x − y = 0. Read the bottom entries and you get −x + 2y = 3. Nothing has changed except the point of view.

Each stack of numbers is a vector: an arrow from the origin. The red column is the arrow to (2, −1). The blue column is the arrow to (−1, 2). The right-hand side is the arrow to (0, 3).

Multiplying a vector by a number stretches it. Adding two vectors means walking along one and then the other. Doing both, x times one vector plus y times another, is called a linear combination. It is the single most important operation in the whole subject.

So the column picture asks a different question from the row picture: how much of the red arrow and how much of the blue arrow do I need to land exactly on the target? The answer is again x = 1, y = 2: one red arrow, then two blue arrows, and you arrive at (0, 3).

Robotics linkactuation

Every motor owns one column

Picture a robot arm with two joints. Turn only the shoulder a little, and the hand sweeps in some direction. Turn only the elbow, and the hand moves in a different direction. Those two hand-velocity arrows are the two columns of a matrix that roboticists call the Jacobian, written J.

To push the hand in a direction you choose, the controller has to decide how fast to turn each joint. That is the column picture exactly: how much of column 1 and how much of column 2 add up to the velocity I want? The joint speeds are the unknowns x and y.

Key idea

Rows are constraints. Columns are capabilities. The row picture asks "where do all my facts agree?" The column picture asks "can my building blocks produce what I want?"

1.3

The matrix form: Ax = b

One short sentence that holds the whole system.

Writing out every equation gets tiring fast, so we pack the numbers into three boxes. The coefficients go into a rectangle called a matrix, named A. The unknowns go into a vector x. The right-hand sides go into a vector b.

The lecture's example as A x = b
=

The rows of A are the two equations. The columns of A are the two arrows. One matrix carries both pictures.

How to multiply a matrix by a vector

There are two ways, and they always give the same answer. Strang recommends the first.

  • By columns. Ax is a combination of the columns of A. The entries of x say how much of each column to take.
  • By rows. Each entry of the answer is one row of A multiplied into x, entry by entry, and summed. This is called a dot product.

Robotics linkhow robot code is written

In robot software, the matrix is the robot

The matrix A stores the machine's geometry: where the wheels are, how long the links are, which way the thrusters point. The vector x is what the motors do right now. The product Ax is the motion that results. Predicting motion from motor commands is a multiplication. Finding motor commands for a wanted motion is solving Ax = b. Robotics names these two directions forward and inverse problems.

1.4

Three equations, three unknowns

The same two pictures, one dimension up.

The lecture then moves to three unknowns:

The lecture's 3 by 3 example
2x − y = 0  −x + 2y − z = −1  −3y + 4z = 4
=

Row picture. With three unknowns, one equation no longer gives a line. It gives a flat sheet, a plane, in three-dimensional space. Two planes meet along a line. A third plane cuts that line at a single point. That point is the solution. Strang admits on camera that this is hard to draw, and with more unknowns it becomes impossible to picture at all.

Column picture. This view survives. The three columns of A are three arrows in space, and we look for the mix that reaches b:

x+ y+ z=

Look closely: the target b is the third column. So take none of the first, none of the second and one of the third. The solution is x = 0, y = 0, z = 1, found by looking, with no algebra. Change the target to (1, 1, −3) and the answer becomes (1, 1, 0), because that target is column 1 plus column 2.

Robotics linkthrust allocation

Three thrusters, three things to control

A small underwater vehicle seen from above can do three things: push forward, push sideways and turn. Call the wanted push and turn b = (Fx, Fy, τ). It has three thrusters, and firing one of them at full unit strength gives some fixed mix of forward push, side push and turning effort. That mix is the thruster's column.

The pilot moves a joystick to ask for b. The computer has to work out how hard to fire each thruster. That is Ax = b with three equations and three unknowns, and the job has a name in marine robotics: thrust allocation.

1.5

The big question: can we solve Ax = b for every b?

The question the lecture ends on, and the one the rest of the course answers.

Strang closes with a question in two forms that mean the same thing:

  • Algebra: can I solve Ax = b for every right-hand side b?
  • Geometry: do the linear combinations of the columns fill the whole space?

For the lecture's matrix the answer is yes. Its three columns point in three truly different directions, so their mixes reach every point of three-dimensional space. Such a matrix is called non-singular or invertible.

The answer is no when the columns are short of directions. If the third column happens to lie in the same plane as the first two, it adds nothing new. All the mixes stay in that plane, and any b outside the plane has no solution. That is a singular matrix. You saw it in Lab 1.7 the moment all three thrusters aimed at the centre.

The idea scales. Nine equations in nine unknowns means nine columns, each an arrow in nine-dimensional space. Nobody can draw that, but the question is unchanged: do the nine columns give nine independent directions?

Robotics linkdesign rule

"Solvable for every b" means "the robot can do everything we ask"

A robot designer reads the lecture's last question like this: do my actuators, between them, cover every motion I need? If the columns of the matrix fill the space, the machine has full authority and any commanded motion can be produced. If they do not, some motion is simply unavailable, whatever the software does. No controller can fix a singular design. Only moving a motor can.

The same question, asked of sensors instead of motors, is whether the robot can work out its full state from what it measures. Lab 1.2 failed in exactly that way when the two bearing lines became one.

1.6

Practice problems

Nine problems, from first steps to robot design. Work each on paper, then open the solution. Every answer has been checked by the code for this lecture.

P1Draw the row picture of x + y = 5 and x − y = 1. Where do the lines cross?rows

The first line passes through (5, 0) and (0, 5). The second passes through (1, 0) and (0, −1). Add the two equations and y cancels: 2x = 6, so x = 3. Put that back into the first equation: y = 2.

Answer: the lines cross at (3, 2). Check: 3 + 2 = 5 and 3 − 2 = 1.

P2Write the system of P1 in the column picture and check your solution with it.columns
x+y=

With x = 3, y = 2: three of (1, 1) is (3, 3), two of (1, −1) is (2, −2), and their sum is (5, 1).

P3Multiply by twice: once by columns, once by rows.A times x

By columns: 2 of the first column minus 1 of the second: 2(1, 3) − (2, 4) = (0, 2).

By rows: first entry 1·2 + 2·(−1) = 0, second entry 3·2 + 4·(−1) = 2.

Answer: (0, 2) both ways.

P4For which number k does x + 2y = 3, 2x + ky = 6 stop having exactly one solution? What happens then, and what if the 6 were a 7?singular

The system is singular when the second row is a multiple of the first. Doubling the first row gives 2x + 4y, so k = 4.

With k = 4 and right-hand side 6 the second equation is exactly twice the first. Both rows draw the same line, so there are infinitely many solutions.

With k = 4 and right-hand side 7 the left sides still match but the right sides do not. The lines are parallel and there is no solution.

Column view of the same fact: the columns (1, 2) and (2, 4) point along one line, so their combinations can only reach right-hand sides on that line. (3, 6) is on it. (3, 7) is not.

P5For the lecture's matrix , solve Ax = b by looking at the columns, with no elimination, for b = (2, −1, 0), then (−1, 1, 1), then (4, −1, −4).columns
  1. (2, −1, 0) is column 1. So x = (1, 0, 0).
  2. (−1, 1, 1) is column 2 plus column 3: (−1, 2, −3) + (0, −1, 4). So x = (0, 1, 1).
  3. (4, −1, −4) is twice column 1 minus column 3: (4, −2, 0) − (0, −1, 4). So x = (2, 0, −1).

The habit to build: before computing, compare the target with the columns.

P6A robot with a compass sees beacon A, at (4, 6), at a bearing of 45°, and beacon B, at (7, 1), due east (bearing 0°). Write the two equations and find the robot.robot

Each bearing φ to a beacon at (p, q) gives the line (sin φ) x − (cos φ) y = (sin φ) p − (cos φ) q.

Beacon A, φ = 45°: the sine and cosine are equal, so divide them out: x − y = 4 − 6 = −2.

Beacon B, φ = 0°: sine is 0 and cosine is 1, so −y = −1, which is y = 1.

Then x = y − 2 = −1. The robot is at (−1, 1).

Check with geometry: from (−1, 1) beacon A is 5 across and 5 up, which is 45°. Beacon B is 8 across and 0 up, which is due east.

Follow-up: the fix fails anywhere on the straight line through A and B, because both bearings then describe that one line.

P7A two-link arm has two links of length 1. The shoulder is at 0° and the elbow is bent 90°, so the elbow is at (1, 0) and the hand at (1, 1). Find the Jacobian, then the joint speeds that move the hand straight up at 1 unit per second.robot

Each column is the arrow from that joint to the hand, turned a quarter turn anticlockwise. Turning (a, b) a quarter turn gives (−b, a).

  • Shoulder at (0, 0): arrow to the hand is (1, 1), turned it is (−1, 1).
  • Elbow at (1, 0): arrow to the hand is (0, 1), turned it is (−1, 0).
J=

We want q̇1(−1, 1) + q̇2(−1, 0) = (0, 1). The bottom entries give q̇1 = 1. The top entries give −1 − q̇2 = 0, so q̇2 = −1.

Answer: the shoulder turns at +1 rad/s and the elbow at −1 rad/s. The shoulder alone would also drag the hand left, and the elbow cancels that part.

Follow-up: straighten the elbow. The hand is at (2, 0) and the columns become (0, 2) and (0, 1). They are parallel, so the hand can only move up or down. Moving it along the arm, in the direction (1, 0), has no solution.

P8A vehicle has thruster 1 at (−1, 1) and thruster 2 at (−1, −1), both pushing forward (along +x), and thruster 3 at the centre (0, 0) pushing sideways (along +y). Write the matrix, decide whether it is singular, and find the thrusts for b = (Fx, Fy, τ) = (2, 1, 1).robot

A thruster at (x, y) pushing along angle a has the column (cos a, sin a, x sin a − y cos a). For the two forward thrusters a = 0, so the torque entry is −y: −1 for thruster 1 and +1 for thruster 2. Thruster 3 sits at the centre, so its torque entry is 0.

=

Row 2 gives f3 = 1. Rows 1 and 3 give f1 + f2 = 2 and −f1 + f2 = 1. Add them: 2f2 = 3.

Answer: f = (0.5, 1.5, 1). The same steps work for any right-hand side, so the matrix is not singular: this layout can produce every push and turn.

Follow-up: slide thrusters 1 and 2 onto the centre line (y = 0). Both torque entries become 0, the bottom row is all zeros, and the vehicle can no longer turn.

P9The lines x + y = 2 and x + 1.01y = 2.01 cross at (1, 1). A sensor error changes the 2.01 to 2.02. Where do they cross now, and what does that tell a robot designer?robot

Subtract the first equation from the second: 0.01y = 0.02, so y = 2 and then x = 0.

Answer: the crossing jumps from (1, 1) to (0, 2). One measurement changed by half of one per cent and the answer moved by about 1.4 units.

The two lines are almost parallel, so the system is nearly singular, or ill-conditioned. A designer reads this as a warning about geometry, and the cure is to choose measurements whose lines cross at a wide angle. Better arithmetic would not help.

1.7

Check yourself

Answer in your head first, then open each one.

Q1In the row picture, what does one equation in two unknowns look like, and what is the solution of two of them?

Each equation is a straight line. The solution is the point where the two lines cross, because only that point satisfies both equations.

Q2Write 2x − y = 0, −x + 2y = 3 in the column picture.

x times the column (2, −1) plus y times the column (−1, 2) equals the column (0, 3). The solution x = 1, y = 2 says: one of the first column plus two of the second.

Q3Without solving anything, find x if b is exactly the second column of A.

Take one of the second column and none of the others, so x has a 1 in the second position and zeros elsewhere. This is the trick Strang uses when b equals column 3.

Q4A two-link arm is stretched out perfectly straight. Why can it not move its hand directly away from the shoulder?

Each joint can only swing the hand at right angles to the line from that joint to the hand. With the arm straight, both of those directions are the same sideways direction. The two columns of the Jacobian are parallel, so every mix of them is sideways too. Outward is not a combination of the columns. The matrix is singular.

Q5A vehicle has three thrusters and all three push through its centre of mass. Which motion is lost, and how does it show in the matrix?

Turning is lost. A force through the centre makes no torque, so the torque entry of every column is zero. The whole bottom row of the matrix is zero, the three columns lie in one plane, and any b with a non-zero torque has no solution.

Q6Two bearing lines cross at a very thin angle. The system is solvable. Why would a robot still distrust the answer?

A tiny error in either bearing moves the crossing point a long way along the lines. The equations are nearly singular, so the solution is very sensitive to noise. The fix is better geometry: use beacons whose bearing lines cross closer to a right angle.

For your article

One-line summary: a linear system can be read across as constraints that must all agree, or down as building blocks that must add up to a goal.

A robot sentence you can reuse: sensors write the rows, motors own the columns, and a singular matrix is a robot that has run out of directions.

Good figures to capture: Lab 1.2 with a wide crossing next to a thin crossing, and Lab 1.4 with the arm bent next to the arm straight.
