Solving Ax = 0: Pivot Variables, Special Solutions

Lecture 6 said what the nullspace is. This lecture is the algorithm that computes it, for any matrix of any shape. Along the way it produces the single most useful number about a matrix, its rank. For a robot, the rank counts the directions it can truly control, and the free variables count its spare actuators.

7.0

Start here: more motors than jobs

What this lecture solves, and the three things you need from earlier lectures.

Some machines have more motors than jobs. An arm with four joints only has to put its hand on one point of a table. A vehicle with four thrusters only has to push forward, push sideways and turn. A machine like this is called over-actuated: it has actuators to spare.

Spare actuators give spare freedom. There are ways to run the motors that change nothing about the job. The joints turn and the hand stays where it is. The thrusters fire and the hull feels no net push. Lecture 6 gave these do-nothing commands a home: they are the solutions of Ax = 0, and together they form the nullspace of A.

In Lecture 6 we found a nullspace by staring at a small matrix until the answer appeared. That does not scale. This lecture gives the method that always works. It is the elimination of Lecture 2, taken a little further.

What you need to remember

  • From Lecture 1: Ax is a combination of the columns of A. The entries of x say how much of each column to take.
  • From Lecture 2: elimination subtracts a multiple of one row from the rows below it to make zeros. The entry that does the work is called a pivot.
  • From Lecture 6: the nullspace of A is every x with Ax = 0. It always contains x = 0.

One thing is new. The matrix is no longer square. A matrix with m rows and n columns is called m by n, and when the two numbers differ it is a rectangular matrix. The whole lecture works on this one:

The lecture's matrix

Strang asks the class to notice two things before doing any arithmetic. Column 2 is 2 times column 1: (2, 4, 6) against (1, 2, 3). And row 3 is row 1 plus row 2: (1, 2, 2, 2) + (2, 4, 6, 8) = (3, 6, 8, 10). So the columns do not all point in new directions, and neither do the rows. Elimination is not told any of this. Watch it discover both.

Robotics linkreading the shape

The shape of the matrix is the shape of the machine

Each column belongs to one actuator, so n is the number of motors or joints. Each row is one thing the machine has to control, so m is the size of the job.

A four-joint arm that places a point on a table has a matrix with 2 rows (hand speed across, hand speed up) and 4 columns (one per joint). A four-thruster vehicle seen from above has 3 rows (forward force, side force, turning torque) and 4 columns (one per thruster). More columns than rows means actuators to spare. This lecture counts exactly how many, and says what the spare ones can do.

7.1

Elimination on a rectangular matrix

The same row operations as Lecture 2, and one new situation.

We are solving Ax = 0. In Lecture 2 the right-hand side rode along as an extra column. Here the right-hand side is all zeros, and a multiple of zero taken away from zero is still zero. There is nothing to carry, so we work on A alone.

Row operations do not change the solutions. If x satisfies two equations, it satisfies their difference too, and every step can be undone. So the matrix we finish with has exactly the same nullspace as the matrix we started with.

The lecture's elimination
→ →

Column 1. The first pivot is the 1 in the top corner. Row 2 − 2 × row 1 gives (0, 0, 2, 4). Row 3 − 3 × row 1 also gives (0, 0, 2, 4).

Column 2. The next pivot should sit in row 2, column 2. That entry is zero. In Lecture 2 we would look below it for something to exchange into place, but the entry below is zero as well (both tinted blue). There is nothing to use, so column 2 has no pivot. This is the new situation. Do not stop. Stay on row 2 and move right.

Column 3. The second pivot is the 2 in row 2, column 3. Row 3 − row 2 gives (0, 0, 0, 0).

Column 4. The pivot position is now row 3, and row 3 is all zeros. No pivot here either.

The result U is in echelon form. Echelon means staircase: each pivot sits further right than the pivot above it, and everything under the staircase is zero. A square matrix with all its pivots gave a tidy triangle. A rectangular one gives stairs of uneven width.

Both facts from the start have surfaced. Column 2 got no pivot because it adds nothing new after column 1. Row 3 turned into zeros because it adds nothing new after rows 1 and 2.

Robotics linkrepeated measurements

A zero row is an equation the robot already knew

A two-wheeled robot moves with forward speed v and turn rate ω. A sensor on the left wheel reads v − 0.2ω, one on the right wheel reads v + 0.2ω, and a camera pointed at the floor reads v directly. Three equations, two unknowns. The camera's row is half the left row plus half the right row, so elimination turns it into zeros, just as it did to row 3 of the lecture's matrix.

The third sensor tells the robot nothing new about its motion. It is still worth its weight. Apply the same row operations to the three readings and the last line should also come out as zero. Readings of 0.9, 1.1 and 1.0 m/s give 0. Readings of 0.9, 1.4 and 1.0 give −0.15, which is impossible if all three sensors are honest. A wheel is slipping. Robots use their repeated equations as alarms.

7.2

Rank: count the pivots

One number that says how much the matrix really contains.

Count the pivots in U. That count is the rank of the matrix, written r.

The lecture's count
  so   r = 2

The matrix has 3 rows and 4 columns, which looks like 3 equations in 4 unknowns. The rank says it holds only 2 independent equations. The third was a repeat.

Strang calls the rank the number that matters most about a matrix, more than its number of rows or columns. The size tells you how the matrix is written. The rank tells you what is in it.

A row can hold at most one pivot, and so can a column. So the rank is never larger than the number of rows and never larger than the number of columns: r ≤ m and r ≤ n.

Robotics linktrue degrees of freedom

Rank is the number of directions the machine can really command

It is easy to count motors. It is the rank that counts independent motors. Bolt four thrusters along the centre line of a boat, all pointing forward. Four motors, four columns, and every column is the same: (1, 0, 0). Elimination finds one pivot. The rank is 1 and the boat can push forward or backward and do nothing else.

A healthy arm working on a table has rank 2: its hand can move in every direction on the table. Stretch the arm out straight and each joint can only swing the hand sideways. The columns line up, the second pivot disappears and the rank falls to 1. Lecture 1 called this pose a singularity. Now it has a measurement: a singularity is a drop in rank.

Watch out

On paper a pivot is either zero or it is not. In a robot the numbers come from sensors, and a pivot of 0.000001 is a zero in disguise. Software has to pick a small threshold and treat anything below it as zero. Close to a singularity the rank on paper is still 2, yet the machine already behaves as if it were 1.

7.3

Pivot variables and free variables

Sort the columns, and the unknowns sort themselves.

Each column of the matrix multiplies one unknown: column 1 multiplies x1, column 2 multiplies x2, and so on. So when elimination sorts the columns into two kinds, it sorts the unknowns too.

  • A column that holds a pivot is a pivot column. Its unknown is a pivot variable.
  • A column with no pivot is a free column. Its unknown is a free variable.
The lecture's sorting

Pivot columns are 1 and 3, so x1 and x3 are the pivot variables. Free columns are 2 and 4, so x2 and x4 are the free variables. Written out as equations, Ux = 0 says:

x1 + 2x2 + 2x3 + 2x4 = 0   2x3 + 4x4 = 0   0 = 0

Two equations that say something, and four unknowns. Two unknowns are left over, and the word free means what it says: you may give x2 and x4 any values you like.

Once you have chosen them, the pivot variables have no freedom left. Each equation has exactly one pivot variable that the equations below it have not already fixed. So start at the bottom equation and work up, solving for one pivot variable at a time. That is the back-substitution of Lecture 2.

Robotics linkwho leads, who follows

Free actuators lead, pivot actuators compensate

Read x as a list of motor commands and Ax = 0 as "the job is not disturbed". The free variables are the actuators you may command however you please. The pivot variables are the actuators that must then make up for it, so that the net effect stays zero.

Which actuators get called free is bookkeeping. Elimination sweeps from left to right, so the columns that come first claim the pivots. Number the joints in a different order and different joints become free. The set of do-nothing commands is the same whatever the order. Only its description changes.

7.4

Special solutions

Switch on one free variable at a time.

Any choice of the free variables gives a solution. Two choices are as simple as a choice can be: set one free variable to 1 and all the others to 0. The solutions that come out are called the special solutions.

The lecture's two special solutions

First choice: x2 = 1, x4 = 0. The second equation, 2x3 + 4x4 = 0, gives x3 = 0. The first, x1 + 2x2 + 2x3 + 2x4 = 0, becomes x1 + 2 = 0, so x1 = −2.

Second choice: x2 = 0, x4 = 1. The second equation becomes 2x3 + 4 = 0, so x3 = −2. The first gives x1 = −2x3 − 2x4 = 4 − 2 = 2.

   

Check them against the original A. The first says: −2 of column 1 plus 1 of column 2 is zero. That is the fact we noticed at the start, column 2 is twice column 1. The second says: 2 of column 1, minus 2 of column 3, plus column 4 is zero. Try it: (2, 4, 6) − (4, 12, 16) + (2, 8, 10) = (0, 0, 0). Nobody would spot that one by eye.

Robotics linkbasic self-motions

A special solution is one clean way to move without disturbing the job

A motion of the joints that leaves the hand where it is has a name in robotics: a self-motion. On an arm with two free joints, special solution 1 reads: turn free joint A at one unit of speed, hold free joint B still, and let the pivot joints compensate. Special solution 2 swaps the roles of A and B. Each one isolates a single spare joint, which makes them easy to understand and easy to test on a real machine.

7.5

The whole nullspace, and the count n − r

Two special solutions are enough to build every solution.

Multiply a solution of Ax = 0 by any number and it is still a solution. Add two solutions and the sum is a solution. That was the subspace rule of Lecture 6. So every combination of the special solutions lies in the nullspace.

And nothing is missing. A solution is completely decided by its free variables. The combination below has x2 = c and x4 = d, so by choosing c and d it can match the free variables of any solution, and then the pivot variables must match too.

The lecture's nullspace
x = c+d

The nullspace of A is all of these: a flat two-dimensional sheet through the origin of four-dimensional space.

The count. There is one special solution for each free variable. The matrix has n columns and r of them hold pivots, so n − r are free. Here n − r = 4 − 2 = 2.

Key idea

The rank r counts what the matrix can do. The number n − r counts what can be done to no effect. The two always add up to n, the number of columns.

Robotics linkredundancy

n − r is how much redundancy the machine has

Roboticists call n − r the degree of redundancy. It is the number of independent ways the actuators can move with no effect on the job.

The four-joint arm has n = 4 joints and rank 2, so 4 − 2 = 2: two independent self-motions, where the three-joint arm of Lecture 6 had one. The four-thruster vehicle has rank 3, so 4 − 3 = 1: a single pattern of thrusts that cancels itself exactly. Fired alone, that pattern does nothing except drain the battery. Section 7.9 shows why engineers are glad to have it anyway.

7.6

Reduced row echelon form R

Clean the matrix until the answer can simply be read off it.

U was enough to solve the problem. Strang takes the matrix further anyway, because the fully cleaned form shows the solutions with no back-substitution at all. Two more kinds of row operation are allowed:

  • Eliminate upward. Use each pivot to make zeros above it as well as below it.
  • Scale. Divide each pivot row by its pivot, so that every pivot becomes 1.

The result is the reduced row echelon form, written R. In software it is a single command, rref(A), which Strang runs during the lecture.

From U to R in the lecture
→ →

These are still row operations, so Rx = 0 has the same solutions as Ax = 0. Read R one row at a time:

x1 + 2x2 − 2x4 = 0   x3 + 2x4 = 0

Each equation now contains one pivot variable and, apart from that, only free variables. Move the free ones across and the answer is in front of you: x1 = −2x2 + 2x4 and x3 = −2x4.

Robotics linkthe compensation rule

Each row of R is an instruction to one pivot actuator

In U the pivot actuators are tangled together: you need the answer for one before you can work out the next. In R they are untangled. Every non-zero row names a single pivot actuator and says what it must do in terms of the free ones alone. A controller can use the row as it stands: take the commands going to the free actuators, multiply by the numbers in the row, flip the sign, and send the result to that pivot actuator.

7.7

The pattern inside R, and the nullspace matrix N

Once R is known, the special solutions need no calculation.

Look at the pivot columns of R, columns 1 and 3. They read (1, 0, 0) and (0, 1, 0). Put side by side, with the zero row left off, they are the identity matrix I, the matrix with ones on the diagonal that changes nothing when it multiplies (Lecture 3). There are r pivots, so this I is r by r.

The free columns, 2 and 4, hold whatever numbers elimination left there. Call that block F.

The blocks of the lecture's R
   

If the pivot columns stood first, R would read as four blocks: I then F on top, and zeros underneath. Strang writes this as R = [ I F ; 0 0 ]. The zero row at the bottom is the record that row 3 of A was a combination of the rows above it.

Now gather the special solutions as the columns of one matrix. Strang calls it the nullspace matrix N.

The lecture's nullspace matrix
   

Every column of N solves Rx = 0, so RN = 0. With the pivot variables listed on top and the free variables below, N = [ −F ; I ]. Multiply the blocks to see why it works: [ I F ] times [ −F ; I ] is −F + F = 0.

The two pictures trade places. In R the identity sits in the pivot columns and F in the free columns. In N the identity sits in the free rows, because each free variable takes its turn to be 1, and −F fills the pivot rows. This second identity is n − r by n − r, one row for each free variable.

xpivot = −F xfree

That one line is the whole lecture. Once R is known, copy its free columns, flip the signs, and place them in the pivot positions: (−2, 0) and (2, −2). The right-hand panel of Lab 7.2 shows exactly this.

Robotics linka control law

xpivot = −F xfree is something a robot can execute

For the four-joint arm in its staircase pose (next section) the block is F = [ 1/2 −1/2 ; 0 1 ]. Say you want the two free joints, 3 and 4, to turn at 0.4 and −0.2 radians per second. Multiply by −F: the pivot joints, 1 and 2, must turn at −0.3 and 0.2. Send those four speeds to the motors and the hand does not move. The controller repeats the multiplication many times a second, with a fresh F each time, because F changes as the arm changes shape.

7.8

The robot: spare joints

The whole lecture, run on a four-joint arm.

The arm has four links of 1 metre each, joined end to end by four turning joints, and it works on a flat table. Its job is to hold its hand at a point. That is 2 numbers to control with 4 joints.

Its matrix is the Jacobian J of Lecture 1. Column i is the hand's velocity when only joint i turns, at one radian per second. Geometrically it is the arrow from joint i to the hand, turned a quarter turn. The joint speeds are the unknowns, and Jq̇ = 0 means "the hand stays still".

Bend the arm into a staircase: up, right, up, right. The joints sit at (0, 0), (0, 1), (1, 1) and (1, 2), and the hand is at (2, 2). The arrow from joint 1 to the hand is (2, 2), which a quarter turn sends to (−2, 2). The other three columns come the same way.

The staircase pose, start to finish
→ →

Two pivots, so the rank is 2 and the hand can be moved in any direction on the table. Joints 1 and 2 are the pivot joints. Joints 3 and 4 are free, and n − r = 4 − 2 = 2. Reading −F off the free columns of R gives the two special solutions:

The first reads: turn joint 3 at 1 rad/s, hold joint 4, turn joint 1 backwards at half that speed, and leave joint 2 alone. Check it in J: (−2)(−1/2) + (−1)(1) = 0 across, and (2)(−1/2) + (1)(1) = 0 up. The hand does not move.

Robotics linkredundant arms

Two spare joints are two things the arm can do while it works

Every self-motion of this arm is some amount of special solution 1 plus some amount of special solution 2. Engineers spend that freedom on side jobs that must not disturb the tool: bending the elbow away from an obstacle, keeping each joint clear of the end of its travel, or steering the whole arm away from singular poses. Arms with seven joints are built for exactly this, because holding a tool in space takes six.

The model here is deliberately simple. It is flat, the joints are ideal and nothing has weight. A real arm adds a third dimension and more rows to J, and the counting works in the same way.

7.9

The robot: spare thrusters, and losing one

One special solution, and three good uses for it.

Lecture 1 drove an underwater vehicle with three thrusters, which is exactly enough for forward force Fx, side force Fy and turning torque τ. Give it a fourth thruster and the matrix becomes 3 by 4. As before, one newton from a thruster mounted at (x, y) and pushing along the angle a contributes the column (cos a, sin a, x sin a − y cos a).

Take a layout that many working vessels use. Two propellers at the stern push forward: T1 on the left at (−1.3, 0.5) and T3 on the right at (−1.3, −0.5). Two side thrusters push to the left: T2 at the bow, (1, 0), and T4 near the stern, (−1, 0). Distances are in metres.

The four-thruster matrix, reduced
→  

Row 3 + ½ row 1, then row 3 − row 2, gives three pivots, all equal to 1. The rank is 3, so the vehicle has full control, and n − r = 4 − 3 = 1: one free thruster and one special solution, s = (−2, −1, 2, 1).

Read it as thrusts in newtons. The two propellers push against each other, −2 and +2, which makes no net force but twists the hull by 2 newton-metres one way. The two side thrusters push against each other, −1 and +1, and twist it by 2 newton-metres the other way. Everything cancels. Bs = 0.

Why keep a pattern that does nothing?

Because any amount of it can be added to the thruster commands and the vehicle will not notice. If f produces the push you want, so does f + cs for every number c. That choice is worth having.

  • Share the load. Ask for a 1 newton push to the side. With the free thruster held at zero, elimination answers (1, 1, −1, 0): the bow thruster pushes, and the two propellers fight each other to cancel the twist. Total thrust 3 newtons. Add half of s and the answer becomes (0, ½, 0, ½): the two side thrusters share the push. Total thrust 1 newton, for the same motion.
  • Stay out of the dead zone. A propeller answers slowly and unevenly close to zero thrust. Adding some of s lets opposing thrusters lean on each other, so each one keeps working in the range where it responds well.
  • Survive a failure. A failed thruster is a deleted column. Delete any one column of this B and the remaining 3 by 3 matrix still has rank 3. Delete a second and only two columns are left. Two columns can hold at most two pivots, so a direction is lost.

The special solution even says which thrusters are safe to lose. A thruster can fail without loss of control exactly when its entry in s is not zero. A non-zero entry means that thruster's column can be rebuilt from the other three, so they can cover for it. Here all four entries are non-zero. The second layout in the lab has s = (1, −2, 1, 0), and its fourth thruster has no understudy.

Robotics linkthrust allocation

One answer plus any amount of the nullspace

Thrust allocation on an over-actuated vehicle is done in two parts. First find one set of thrusts that produces the wanted push and turn. The lab does it the lecture's way: set the free variable to zero and back-substitute for the pivot variables. Then add whatever multiple of the special solution suits the machine best. Lecture 8 makes this two-part recipe the official way to solve any Ax = b.

The model is flat, each thruster can push both ways with equal ease, and the water resists motion with a simple drag.

7.10

The transpose has the same rank

The lecture's second example, and a fact that seems too neat to be true.

Strang ends by running the whole method again on a second matrix. He takes the transpose of A: the matrix whose rows are the columns of A (Lecture 5). It has 4 rows and 3 columns.

The lecture's second example
→ →

Subtracting 2 × row 1 from each row below leaves (0, 0, 0), (0, 2, 2) and (0, 4, 4). The pivot position in column 2 holds a zero, but there is a 2 below it, so this time a row exchange finds the pivot. One more subtraction clears the last row.

Pivots in columns 1 and 2. The rank is 2 again. But now there are only 3 columns, so n − r = 3 − 2 = 1: one free variable, x3, and one special solution.

From R: F is the single column (1, 1), so the special solution is x = (−1, −1, 1), and the nullspace of AT is every multiple c(−1, −1, 1): a line. Read the special solution as a statement about columns: column 3 of AT is column 1 plus column 2. Those columns are the rows of A. It is the fact we noticed at the very start, row 3 = row 1 + row 2, found by the algorithm.

The rank came out the same, and that is no accident of this example. A matrix and its transpose always have the same rank. The number of independent columns equals the number of independent rows. What differs is the number of free variables: n − r for A and m − r for AT.

Robotics linkmotion and force

The same count, read as motion and read as force

Lecture 5 showed that an arm uses its Jacobian twice. Joint speeds go through J to become hand velocity. A force at the hand goes through JT to become the torques the joints must supply. Equal ranks mean the two readings agree: the number of independent directions in which the hand can move equals the number of independent directions in which the motors can push it.

In the staircase pose both ranks are 2 and JT has m − r = 2 − 2 = 0 free variables: every force at the hand needs some torque. Stretch the arm straight and both ranks fall to 1. Now JT has one free variable, and its special solution is a force along the arm. The motors feel nothing from it, because the links carry it like a pole. You do the same when you lock your arm straight to lean on a wall.

Ten problems, from first steps to robot design. Work each on paper, then open the solution. Every answer has been checked by the code for this lecture.

P1Eliminate to echelon form. Which columns are pivot columns, which are free, and what is the rank?elimination

Row 2 − 2 × row 1 = (0, 0, 2, 4). Row 3 already starts with a zero.

Column 2: the pivot position in row 2 is zero and so is the entry under it. No pivot. Move right.

Column 3: the pivot is the 2 in row 2. Row 3 − row 2 = (0, 0, 0, 0).

Answer: pivot columns 1 and 3, free columns 2 and 4, rank 2.

P2Find the special solutions of the matrix in P1 by back-substitution in its U.special solutions

The equations are x1 + 3x2 + x3 + 2x4 = 0 and 2x3 + 4x4 = 0. The free variables are x2 and x4.

x2 = 1, x4 = 0: the second equation gives x3 = 0, then the first gives x1 = −3.

x2 = 0, x4 = 1: the second gives x3 = −2, then the first gives x1 = 2 − 2 = 0.

Answer: (−3, 1, 0, 0) and (0, 0, −2, 1). The nullspace is every combination of the two.

Check the second in the original row 2: 2·0 + 6·0 + 4·(−2) + 8·1 = 0.

P3Carry the U of P1 on to R. Write down F and the nullspace matrix N, and compare with P2.rref

Clear above the second pivot: row 1 − ½ × row 2 = (1, 3, 0, 0). Then divide row 2 by 2.

F is what the free columns 2 and 4 hold in the pivot rows. In N, rows 1 and 3 (the pivot variables) are −F and rows 2 and 4 (the free variables) are the identity.

Answer: the columns of N are (−3, 1, 0, 0) and (0, 0, −2, 1), the same as P2, with no back-substitution.

P4Answer by counting, with no elimination. (a) A 3 by 5 matrix has rank 3. How many special solutions? (b) A 5 by 3 matrix has rank 3. What is its nullspace? (c) Can a 3 by 5 matrix have only the zero vector in its nullspace?counting

(a) n − r = 5 − 3 = 2 special solutions.

(b) n − r = 3 − 3 = 0. No free variables, so the nullspace is the zero vector alone.

(c) The rank is at most the number of rows, 3. So n − r is at least 5 − 3 = 2.

Answer: (a) 2. (b) Only x = 0. (c) No. A matrix with more columns than rows always has free variables, so Ax = 0 always has non-zero solutions.

P5For , find the rank and the special solutions of A, then of AT.transpose

A: row 2 − 2 × row 1 = (0, 0, 1). Pivots in columns 1 and 3, so the rank is 2 and x2 is free. With x2 = 1: the second equation gives x3 = 0, the first gives x1 = −2.

AT has rows (1, 2), (2, 4), (1, 3). Row 2 − 2 × row 1 = (0, 0) and row 3 − row 1 = (0, 1). Exchange rows 2 and 3. Pivots in both columns.

Answer: both have rank 2. A has 3 − 2 = 1 special solution, (−2, 1, 0). AT has 2 − 2 = 0, so its nullspace is the zero vector alone.

P6A four-joint arm with 1 m links lies along the table for two links and then turns straight up for two. Its joints are at (0, 0), (1, 0), (2, 0), (2, 1) and its hand is at (2, 2). Find J, its rank, the pivot and free joints, and the special solutions.robot

Each column is the arrow from that joint to the hand, turned a quarter turn: (a, b) becomes (−b, a). The arrows are (2, 2), (1, 2), (0, 2), (0, 1).

→→

Row 2 + row 1 gives U. Then row 1 − 2 × row 2, and divide the rows by −2 and −1.

Answer: rank 2. Joints 1 and 2 are pivot joints, joints 3 and 4 are free. Flipping the signs of the free columns of R: special solutions (1, −2, 1, 0) and (½, −1, 0, 1).

Check the first: across, −2 + 4 − 2 = 0. Up, 2 − 2 = 0.

P7In the pose of P6, joint 3 must turn at 0.2 rad/s to move the elbow away from an obstacle, and joint 4 must not turn. What should joints 1 and 2 do so that the hand stays still?robot

The free joints are 3 and 4, and the request is free speeds (0.2, 0). That is 0.2 of special solution 1 and none of special solution 2.

0.2 × (1, −2, 1, 0) = (0.2, −0.4, 0.2, 0).

Answer: joint 1 at 0.2 rad/s and joint 2 at −0.4 rad/s. Check: across, −2(0.2) − 2(−0.4) − 2(0.2) = 0. Up, 2(0.2) + 1(−0.4) = 0.

Follow-up: if joint 4 also had to turn at 0.2, add 0.2 × (½, −1, 0, 1). The joint speeds become (0.3, −0.6, 0.2, 0.2).

P8The same arm is stretched straight up the page: joints at (0, 0), (0, 1), (0, 2), (0, 3), hand at (0, 4). Find J, its rank and n − r. Which hand motion is lost?robot

The arrows to the hand are (0, 4), (0, 3), (0, 2), (0, 1). Turned a quarter turn they are (−4, 0), (−3, 0), (−2, 0), (−1, 0).

→

Answer: rank 1 and n − r = 3, with special solutions (−¾, 1, 0, 0), (−½, 0, 1, 0) and (−¼, 0, 0, 1). The second row of J is zero, so the hand cannot move up or down the page, which is the direction along the arm. This pose is a singularity.

The third special solution is no bonus. The arm bought it by giving up a direction of hand motion.

P9A vehicle has two propellers at (−1, 1) and (−1, −1) pushing forward (T1, T2), and two side thrusters at (1, 0) and (−1, 0) pushing to the left (T3, T4). Write B, find its rank and its special solution, and say which single thrusters can fail without loss of control.robot

A thruster at (x, y) pushing along +x gives the column (1, 0, −y). Pushing along +y it gives (0, 1, x).

→→

Row 3 + row 1 = (0, 2, 1, −1). In column 2 the pivot position holds a zero with a 2 below it, so exchange rows 2 and 3. For R: row 2 − row 3, divide row 2 by 2, then row 1 − row 2.

Answer: rank 3, one free thruster (T4), special solution s = (−1, 1, −1, 1). Every entry of s is non-zero, so any one thruster can fail and the other three still give rank 3.

Check Bs: −1 + 1 = 0, −1 + 1 = 0, and 1 + 1 − 1 − 1 = 0.

P10The pilot of the vehicle in P9 asks for a pure side push, b = (0, 2, 0). Find the thrusts with the free thruster at zero, then the thrusts with the least total thrust.robot

With f4 = 0: row 2 gives f3 = 2. Row 1 gives f2 = −f1. Row 3, −f1 + f2 + f3 = 0, gives f1 = 1. So f = (1, −1, 2, 0), a total of 4 N.

Every other answer is f + cs = (1 − c, −1 + c, 2 − c, c). At c = 1 both propellers switch off.

Answer: (1, −1, 2, 0) with the free thruster at zero, and (0, 0, 1, 1) for least effort: the two side thrusters share the push, 2 N in total.

Follow-up: if T4 has failed, c is stuck at 0 and the 4 N answer is the only one.

Check yourself

Answer in your head first, then open each one.

Q1Why is no extra column carried along when we eliminate to solve Ax = 0?

The right-hand side is all zeros, and every row operation subtracts a multiple of one zero from another. It stays all zeros, so writing it down would add nothing.

Q2During elimination the pivot position holds a zero. When does that make the column free, and when does it not?

Look below the zero in the same column. If there is a non-zero entry, exchange rows and you have a pivot. If everything below is zero too, there is no pivot: the column is free, and elimination moves one column to the right without moving down a row.

Q3A matrix has 4 columns and its echelon form has pivots in columns 1 and 3. What is its rank, which variables are free, and how many special solutions are there?

Rank 2, because there are two pivots. The free variables are x2 and x4. There is one special solution per free variable, so n − r = 4 − 2 = 2.

Q4R has rows (1, 0, 1), (0, 1, 1), (0, 0, 0), (0, 0, 0). Write F and the special solution without calculating.

The pivot columns are 1 and 2 and the free column is 3, so F is the column (1, 1). Flip the signs for the pivot variables and put 1 in the free position: x = (−1, −1, 1). This is the lecture's second example.

Q5A robot has six motors and its matrix has rank 4. How many directions can it truly command, and how many independent ways can it run its motors with no effect?

It commands 4 independent directions, the rank. It has n − r = 6 − 4 = 2 independent do-nothing patterns. Counting motors would have given the wrong answer to both questions.

Q6A four-thruster vehicle with full control has the special solution (1, −2, 1, 0). Which thruster must never fail, and why?

The fourth. Its entry is zero, which means the special solution is a combination of the first three columns alone that adds to zero. Those three columns are dependent, so without the fourth they cannot give rank 3. Each of the other thrusters has a non-zero entry and can be covered by the remaining three.

Q7A is 3 by 4 with rank 2. How many free variables does A have, and how many does AT have?

A has 4 − 2 = 2. AT is 4 by 3 with the same rank 2, so it has 3 − 2 = 1. These are the numbers of the lecture's two examples.

For your article

One-line summary: elimination sorts the unknowns into pivot variables and free variables; the pivots count what the matrix can do, and the free variables generate everything it can do to no effect.

A robot sentence you can reuse: rank is the number of directions a machine can really command, n − r is the number of actuators it has to spare, and a special solution is one spare actuator leading while the others cover for it.
